Пакет переименован: `ebely` → `eberly`. Старый `ebely` больше не
обновляется. Обратной совместимости нет — алиасов старых имён нет.

Миграция:

- `npm uninstall ebely && npm i -D eberly`.
- Импорты `from 'ebely'` → `from 'eberly'`; типы и классы
  `Ebely*` → `Eberly*` (`EberlyConfig`, `EberlyUnsafeHostError`,
  `EberlyAssertionError`, `EberlyHookTree`, `generateEberlyClient`).
- Папка `ebely/` → `eberly/`, конфиг `ebely/ebely.ts` → `eberly/eberly.ts`
  (и пути в `tsconfig.json` / `configImport`, если указаны явно).
- **Удалить старую `ebely/api/`** (или `eberly/api/` после переименования
  папки) перед `client:generate`: старые файлы несут прежний маркер
  `AUTO-GENERATED by ebely`, генератор их не узнает и не удалит.
- CLI: `npx ebely …` → `npx eberly …`. Переустановить скиллы:
  `npx eberly skills` (теперь `/eberly-setup` и `/eberly-write-tests`),
  старые `.claude/skills/ebely-*` удалить.
