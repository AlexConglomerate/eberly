Описания эндпоинтов: JSDoc в клиенте и папка `api/` для агента.

- JSDoc из свагера: у метода в `WorldApi` — summary, description, маршрут
  (`` `POST /posts` ``) и `@deprecated`; у path/query-параметров и полей
  схем — их description (у полей ещё `@deprecated`). `*/` в описаниях
  экранируется.
- `client:generate` теперь пишет рядом с клиентом папку `api/`:
  `INDEX.md` (строка на эндпоинт) и `<группа>.<метод>.md` с описанием,
  готовым вызовом, входом, ответами и типами. Агент читает их вместо
  всего `generated.ts`. Перед записью удаляются только файлы с маркером
  `AUTO-GENERATED by ebely` — чужие файлы в папке не трогаются.
  Рекомендуется коммитить эту папку.
- `generateClient` возвращает ещё `docsDir`.
