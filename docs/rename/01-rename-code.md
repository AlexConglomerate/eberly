# 01. Переименовать код: ebely / evely → eberly

> Контекст — [README.md](README.md). Перед стартом прочитай
> [HANDOFF.md](HANDOFF.md). Ветка `New-features`, один коммит.

## Что сделать

Заменить во всём репозитории (кроме исключений ниже) все формы имени:

| Было | Стало |
|------|-------|
| `ebely` | `eberly` |
| `Ebely` (`EbelyConfig`, `EbelyUnsafeHostError`, `EbelyAssertionError`, `EbelyHookTree`, `generateEbelyClient`, …) | `Eberly…` |
| `EBELY` (если встретится) | `EBERLY` |
| `evely` (URL репозитория в `package.json`, `ROADMAP.md`, …) | `eberly` |

### Переименования файлов и папок (`git mv`, чтобы сохранить историю)

- `bin/ebely.mjs` → `bin/eberly.mjs`; в `package.json` → `"bin": { "eberly": "bin/eberly.mjs" }`.
- `skills/ebely-setup` → `skills/eberly-setup`, `skills/ebely-write-tests` → `skills/eberly-write-tests`
  (и `name:` во frontmatter `SKILL.md`, и все `/ebely-…` в тексте).
- `examples/{simple,simple-auth,nest}/test-with-ebely` → `test-with-eberly`.
- Внутри каждого: папка `ebely/` → `eberly/`, `ebely/ebely.ts` → `eberly/eberly.ts`.
- Имена workspace-пакетов `@ebely-examples/*` → `@eberly-examples/*`
  (в их `package.json`, в `scripts/e2e.ts`, в `CLAUDE.md`).

### Места, которые легко пропустить

- `.changeset/*.md` — frontmatter `"ebely": minor` → `"eberly": minor`.
  Иначе `changeset version` в задаче 02 упадёт: пакета `ebely` в репо уже нет.
- `src/generator/docs.ts` — `DOCS_MARKER` (`AUTO-GENERATED by ebely`).
- `bin/eberly.mjs` — `"include": ["ebely", "tests"]` в шаблонном tsconfig,
  дефолтное имя `ebely-tests`, зависимость `ebely: ^version`, тексты help.
- `scripts/e2e.ts` — пути `test-with-ebely`, `ebely/ebely.ts`, проверка
  `pkg.dependencies.ebely`, префикс временной папки `ebely-create-`.
- `scripts/sync-template.ts` — путь к примеру.
- `tsconfig.json` примеров — `include`.
- Импорты в тестах примеров (`../ebely/...`).
- `CLAUDE.md`, `claude.md`, `ARCHITECTURE.md`, `RELEASE.md`, `README.md`.
- `pnpm-lock.yaml` — не править руками: `pnpm install` после переименований.

### README и CHANGELOG

- `README.md`: в самый низ строку
  `Formerly published as [`ebely`](https://www.npmjs.com/package/ebely).`
- `CHANGELOG.md`: заголовок `# ebely` → `# eberly`; старые записи не трогать.
- Добавить changeset `.changeset/rename-to-eberly.md` (`"eberly": minor`):
  что пакет переименован и как мигрировать — `npm i -D eberly`,
  заменить импорты и `Ebely*` → `Eberly*`, папку `ebely/` → `eberly/`,
  **удалить старую `ebely/api/`** перед `client:generate` (старые файлы
  несут старый `DOCS_MARKER`, генератор их не узнает и не удалит),
  переустановить скиллы `npx eberly skills`.

### Исключения (НЕ переименовывать)

- Записи `CHANGELOG.md` до 0.2.0.
- `docs/plan/`, `docs/file-upload-plan.md` — завершённые планы, история.
- `docs/rename/` — этот план.
- Git-теги `ebely@*`.

## Как проверить

1. `pnpm install`, `pnpm build`, `pnpm lint`, `pnpm test`.
2. `pnpm e2e` — пересоздаёт `generated.ts`, `eberly/api/`, `swagger.json`;
   результат закоммитить. Смоук в конце должен создавать `eberly/eberly.ts`
   и `.claude/skills/eberly-*`.
3. Остатков нет:
   ```bash
   git ls-files | grep -v -e '^docs/plan/' -e '^docs/rename/' -e '^docs/file-upload-plan.md' -e '^CHANGELOG.md' \
     | xargs grep -il -e ebely -e evely
   git ls-files | grep -i -e ebely -e evely
   ```
   Обе команды — пусто (кроме ожидаемого: строка «Formerly published as `ebely`»
   в README и текст changeset-а про миграцию).
4. `npm pack --dry-run` — в списке `bin/eberly.mjs`, `skills/eberly-*`.

## Готово, когда

- все проверки выше зелёные, один коммит в `New-features`;
- запись в [HANDOFF.md](HANDOFF.md).
