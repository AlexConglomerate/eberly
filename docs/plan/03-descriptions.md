# 03 — Описания: JSDoc в клиенте и папка `ebely/api/` для агента

> Самодостаточная задача. Общие решения, порядок и принципы тестов — в
> [README.md](README.md). Зависит от 02 (именованные типы, `WorldApi` как
> единственный источник типов).

## Цель

Агент или человек понимает эндпоинт, не открывая код бэкенда и не читая
весь `generated.ts`:

1. **JSDoc.** При наведении на `user.posts.create` IDE показывает summary,
   description, маршрут и `@deprecated`.
2. **Папка `ebely/api/`.** `INDEX.md` — одна строка на эндпоинт; на каждый
   эндпоинт — свой `.md` с описанием, готовым вызовом и типами.

Всё это пишет **обычный код генератора** из свагера при
`client:generate`, без ИИ и детерминированно. Файлы перегенерируются той же
командой, что и клиент, поэтому разойтись с ним не могут.

## Почему это экономит контекст

На API из 200 эндпоинтов `generated.ts` занимает десятки тысяч строк, и
агент его не прочитает. С папкой поток такой: `INDEX.md` (~1 строка на
эндпоинт) → 2–3 файла нужных эндпоинтов → тест.

## Решения

### JSDoc

- **Эндпоинт** (главное) — над методом в `WorldApi`:

  ```ts
  /**
   * Create a post
   *
   * Only for authenticated users. The author is the current user.
   *
   * `POST /posts`
   * @deprecated   ← только если в свагере deprecated: true
   */
  "create": (input: { body: CreatePostDto }) => Promise<ApiResponse<{ 201: PostDto; 400: ErrorDto }>>
  ```

  Маршрут в JSDoc стоит копейки и сразу показывает, куда реально идёт
  запрос.
- **Параметры** — над полями `path` / `query` во входном типе
  (`buildInputType`).
- **Поля схем** — над свойством в объектной ветке `schemaToType`, плюс
  `@deprecated` у поля.

  Поля и параметры — не костыль: рендер и тех и других централизован,
  нужна одна строка комментария в двух местах.
- **Экранирование обязательно.** Description — внешний текст. `*/` внутри
  него закроет комментарий, и остаток описания станет **кодом** в
  `generated.ts` (сломанный файл или, хуже, инъекция кода). Заменяем `*/`
  на `*\/`. Многострочный текст — каждая строка с ` * `.
- Нет описания — нет пустого комментария.
- Общий хелпер `renderJsDoc({ lines, deprecated, indent })` для всех трёх
  мест.

### Папка `ebely/api/`

- **Где.** `<папка generateClientTo>/api/` (в шаблоне это `ebely/api/`).
  Новой опции конфига нет.
- **Файлы.** `INDEX.md` и `<группа>.<метод>.md`. Плоско, и имя совпадает с
  вызовом `user.posts.create`.
- **Формат — `.md` с блоками `ts`.** В файле три вида содержимого: текст,
  пример вызова, типы. `.ts` в папке `ebely/` попал бы в `include` tsconfig,
  и IDE начала бы предлагать автоимпорт `PostDto` из двух мест.
- **Язык заголовков — английский** (библиотека выходит наружу).
- **Маркер в первой строке:**
  `<!-- AUTO-GENERATED by ebely. Do not edit. Regenerate: pnpm run client:generate -->`
- **Удаление устаревших файлов.** Перед записью удаляем в папке **только
  файлы, первая строка которых — маркер**. Никакого `rm -rf`: при
  `generateClientTo: 'src/generated.ts'` папка `src/api/` может оказаться
  кодом пользователя.
- **Коммитить** эти файлы в git: тогда в PR видно изменение API в
  читаемом виде. Пойдёт рекомендацией в README.

`INDEX.md`:

```md
<!-- AUTO-GENERATED by ebely. … -->
# API index
Open `<group>.<method>.md` for details. Call as `user.<group>.<method>(…)`.

## posts
- posts.list — GET /posts — List posts
- posts.create — POST /posts — Create a post
- posts.delete — DELETE /posts/{id} — Delete a post (author only)
## auth
- auth.whoami — GET /auth/whoami — Current user (deprecated)
```

`posts.create.md`:

````md
<!-- AUTO-GENERATED by ebely. … -->
# posts.create — POST /posts

Create a post

Only for authenticated users. The author is the current user.

## Call
```ts
const res = await user.posts.create({ body: { title: "string", content: "string" } })
res.assert(201)
```

## Input
```ts
{ body: CreatePostDto }
```

## Responses
```ts
201: PostDto
400: ErrorDto
401: ErrorDto
```

## Types
```ts
type CreatePostDto = {
  /** Post title */
  title: string
  content: string
}
type PostDto = { … }
type ErrorDto = { … }
```
````

- **Пример вызова строится кодом:**
  - только обязательные поля;
  - значение берётся из `example` в схеме, иначе первое значение `enum`,
    иначе заглушка по типу: `"string"`, `0`, `true`, `[]`, для файла
    `"./path/to/file"`;
  - вложенные объекты рекурсивно, с лимитом глубины 3 и множеством
    посещённых `$ref` (рекурсия);
  - `assert` с первым задекларированным 2xx; в режиме `frontend` — без
    `assert`.
- **Types:** определения всех именованных типов, на которые ссылаются вход
  и ответы. Транзитивно, каждый ровно один раз, обход защищён от рекурсии.
  Инлайн-типы (oRPC) просто стоят на месте в Input/Responses.

## Где править

| Файл | Что |
|------|-----|
| `src/generator/operations.ts` | в `Operation`: `description?`, `deprecated?`; параметры объектами `{ name, description?, required }` вместо строк; сырые схемы тела и ответов (для примера и списка типов) |
| `src/generator/schema.ts` | JSDoc полей; экранирование |
| `src/generator/render.ts` | JSDoc эндпоинта в `WorldApi`, JSDoc параметров в `buildInputType`; `renderJsDoc` |
| `src/generator/docs.ts` (новый) | чистые функции `renderEndpointDocs({ spec, operations, names, mode }): { fileName, content }[]` и `renderExampleValue(...)` |
| `src/generate-client.ts` | удалить файлы с маркером, записать новые; строка в логе `Endpoint docs: ebely/api (N files)` |
| `examples/*/test-with-ebely` | перегенерировать, закоммитить `ebely/api/` |
| `ARCHITECTURE.md`, `CLAUDE.md` | раздел про описания и папку `api/` |

## Тесты

- **JSDoc:**
  - summary + description + маршрут;
  - `deprecated` → `@deprecated`;
  - описание `"a */ b"` → в выводе `*\/`, и комментарий не закрывается
    раньше времени;
  - описания полей и параметров;
  - без описаний — без пустых `/** */`.
- **`docs.test.ts`:**
  - строки `INDEX.md` и группировка;
  - имя файла `posts.create.md`;
  - маркер в первой строке;
  - пример вызова содержит только обязательные поля и берёт `example`;
  - `enum` → первое значение;
  - рекурсивная схема: определения конечны, каждое ровно один раз;
  - `deprecated` помечен;
  - в `frontend` нет `assert`.
- **Очистка** (временная папка через `mkdtemp`): файл с маркером удалён,
  чужой файл без маркера остался.
- **Приёмка руками:** в новой сессии попросить агента написать тест на
  `comments.create`, разрешив читать только `ebely/api/`. По транскрипту
  проверить, что `generated.ts` ему не понадобился.

## Готово когда

- `pnpm test` и `pnpm lint` зелёные;
- у Nest-клиента при наведении на `user.posts.create` видны описание и
  маршрут, у `user.auth.whoami` — зачёркивание;
- `ebely/api/` сгенерирована во всех примерах и закоммичена.
