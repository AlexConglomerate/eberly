A file can also be a `URL`, `{ path, name?, type? }`, `{ content, name }`,
`Blob` or `File`.

A backend may expect other field names for an array of files (oRPC wants
`files[0]`, `files[1]`): see `files` in the [config reference](/reference/config/)
and the [oRPC recipe](/backend-requirements/#orpc).
